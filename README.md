### Приложение для анализа транзакций, которые находятся в Excel-файле, генерирует JSON-данные для веб-страниц,формирует Excel-отчеты

Осуществляются следующие задачи:

1. Веб-страницы: "Главная"

Основные функции для генерации JSON-ответов реализуйте в отдельном модуле views.py

Данные для анализа и вывода на веб-страницах — это данные с начала месяца, на который выпадает входящая дата, по входящую дату.

Если дата — 20.05.2020, то данные для анализа будут в диапазоне 01.05.2020-20.05.2020.

Валюты и акции для отображения на веб-страницах задаются в отдельном файле пользовательских настроек user_settings.json.

Пример:
{
  "user_currencies": ["USD", "EUR"],
  "user_stocks": ["AAPL", "AMZN", "GOOGL", "MSFT", "TSLA"]
}

Реализован набор функций и главная функция, принимающая на вход строку с датой и временем в формате YYYY-MM-DD HH:MM:SS и возвращающая JSON-ответ со следующими данными:

**Приветствие в формате "???", где ??? — «Доброе утро» / «Добрый день» / «Добрый вечер» / «Доброй ночи» в зависимости от текущего времени.**

***Функция get_greeting***
    
    Возвращает приветствие в зависимости от текущего времени.

**По каждой карте:**
- последние 4 цифры карты;
- общая сумма расходов;
- кешбэк (1 рубль на каждые 100 рублей).
- Топ-5 транзакций по сумме платежа.
- Курс валют.
- Стоимость акций из S&P500.

***Функция get_currency_rates***

    Получает актуальные курсы валют (USD, EUR) от Центрального Банка России.

***Функция get_stock_prices***
   
    Получает текущие котировки акций через Alpha Vantage API.

***Функция filter_transactions_by_date***

    Фильтрует транзакции по дате

***Функция calculate_card_statistics***
    
    Рассчитывает статистику по картам: сумма расходов и кэшбэк.

***Функция get_top_transactions***
    
    Возвращает топ-N транзакций по сумме платежа.

***Функция generate_json_response***
    
    Формирует JSON-ответ на основе входящей даты.

***Функция read_transactions_from_excel***
    
    Читает данные из Excel-файла и возвращает список словарей с транзакциями.

***Функция load_user_settings***
    
    Загружает пользовательские настройки из файла user_settings.json.

2. Сервисы: "Инвесткопилка"

Сервис "Инвесткопилка" позволяет копить через округление трат. 
Можно задать комфортный порог округления: 10, 50 или 100 ₽. 
Траты будут округляться, и разница между фактической суммой трат по карте и суммой округления будет попадать 
на счет «Инвесткопилки».


Функция investment_bank принимает на вход три аргумента:
- month — месяц, для которого рассчитывается отложенная сумма (строка в формате 'YYYY-MM').
- transactions — список словарей, содержащий информацию о транзакциях, в которых содержатся следующие поля:
- Дата операции — дата, когда произошла транзакция (строка в формате 'YYYY-MM-DD').
- Сумма операции — сумма транзакции в оригинальной валюте (число).
- limit — предел, до которого нужно округлять суммы операций (целое число).

А возвращает сумму, которую удалось бы отложить в «Инвесткопилку».

#### Пример

Вы настроили шаг округления 50 ₽. Покупка на 1712 ₽ автоматически округлится 
до 1750 ₽, и 38 ₽ попадут в «Инвесткопилку».


3. Отчеты: "Траты по категориям"

**Реализованы отчеты в отдельном модуле reports.py.**

**Создан декоратор для функций-отчетов, который записывает в файл результат, 
который возвращает функция, формирующая отчет.**

Декоратор без параметра — записывает данные отчета в файл с названием по умолчанию.
Декоратор с параметром — принимает имя файла в качестве параметра.

Функция принимает на вход:

- датафрейм с транзакциями,
- название категории,
- опциональную дату. Если дата не передана, то берется текущая дата.

А возвращает траты по заданной категории за последние три месяца (от переданной даты).

***Функция save_report***
    
    Декоратор для сохранения результата функции-отчета в файл.

***Функция spending_by_category***

    Возвращает траты по заданной категории за последние три месяца
